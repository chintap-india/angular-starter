# Security Policy

## Supported Versions

We provide security updates for the current major and minor release versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within the Chintap Angular Starter Kit, please do **NOT** open a public GitHub issue.

Instead, please send an email to **[hello@chintap.com](mailto:hello@chintap.com)** with:
- A description of the vulnerability and potential impact.
- Steps to reproduce the issue or proof-of-concept code.
- Any suggested mitigations.

You will receive an acknowledgment within 48 hours, followed by updates on triage and release of a security patch.
